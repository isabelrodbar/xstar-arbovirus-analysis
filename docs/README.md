# Xstar Arbovirus Study - Exploratory Analysis

Luminex MAGPIX multiplexed bead assay analysis for Uganda cohort samples (Wave 3 & Wave 5).

## View the Analysis

Visit the [Exploratory Analysis Dashboard](index.html) to access:

- **Median MFI Analysis** - Analysis using Median MFI values
- **Net MFI Analysis** - Parallel analysis using Net MFI values

## Analysis Features

- MFI distributions by plate, site, and district
- Wave 3 vs Wave 5 comparisons
- SNAP antigen normalization
- Correlation analyses for DENV and flaviviruses
- Interactive HTML reports with collapsible sections

## Data

- **Samples:** LLINEUP2 participant samples from Uganda
- **Waves:** Wave 3 (7 plates) and Wave 5 (12 plates)
- **Antigens:** 47 antigens across multiple disease panels
  - Arboviruses (DENV, CHIKV, ZIKV, WNV, YFV, etc.)
  - Malaria (Pf, Pv, Pm, Po)
  - NTDs (Leishmania, Schistosomiasis, etc.)
  - Vaccine-preventable diseases
  - Human herpesviruses
